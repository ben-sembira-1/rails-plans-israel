# PR screenshots

Screenshots from local test runs, referenced from pull request descriptions (`pr-<number>/`). Not part of the app.

Images are stored with Git LFS. Embed them with
`https://media.githubusercontent.com/media/ben-sembira-1/rails-plans-israel/pr-assets/pr-<number>/<file>`
(`raw.githubusercontent.com` would return the LFS pointer, not the image).
